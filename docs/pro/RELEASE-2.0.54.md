# Game Panel PRO 2.0.54

- Add Game Server now opens the game template catalog directly from the shared fleet.
- Selecting a game opens its installer with the sidebar node preselected. With All nodes, choose the destination in the installation form.
- The installation form can change the target node without opening Nodes or a legacy runtime list.

Panel update only. Agents 2.0.52 remain compatible; no agent or game restart is required. No database migration.
